# Maulik Gelot - Portfolio Website

A modern, responsive portfolio website showcasing my professional work, skills, and projects.

## Features

- 🎨 **Modern Design**: Clean and professional UI with gradient accents
- 📱 **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- ⚡ **Fast Loading**: Lightweight HTML, CSS, and JavaScript
- 🎯 **Smooth Navigation**: Sticky navbar with smooth scrolling
- 💫 **Animations**: Subtle scroll animations and hover effects
- 🔗 **Easy to Customize**: Well-organized code with clear comments

## Sections

1. **Hero Section**: Eye-catching introduction with call-to-action buttons
2. **About**: Brief professional summary with highlighted expertise
3. **Skills**: Organized technical skills by category
4. **Projects**: Featured project showcase with links to GitHub repositories
5. **Contact**: Easy contact methods and social media links
6. **Footer**: Quick links and copyright information

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Gradients, Transitions)
- Vanilla JavaScript
- Font Awesome Icons

## How to Use

1. Clone this repository
2. Open `index.html` in your web browser
3. Customize the content to match your profile
4. Update links to your social media and projects
5. Deploy to your preferred hosting platform

## Customization

### Update Personal Information
Edit the following in `index.html`:
- Name and headline
- About section text
- Skills list
- Project details
- Contact information

### Modify Colors
Edit the CSS variables in `styles.css`:
```css
--primary-color: #0066cc;
--secondary-color: #00d4ff;
--dark-bg: #0a0e27;
```

### Add More Projects
Duplicate the `project-card` div and update the content:
```html
<div class="project-card">
    <div class="project-header">
        <h3>Your Project Name</h3>
        <div class="project-tags">
            <span class="tag">Technology</span>
        </div>
    </div>
    <p class="project-description">Description here</p>
    <a href="your-link" target="_blank" class="project-link">
        View on GitHub <i class="fas fa-external-link-alt"></i>
    </a>
</div>
```

## Deployment

### GitHub Pages
1. Push to your GitHub repository
2. Go to repository settings
3. Scroll to "GitHub Pages"
4. Select main branch as source
5. Your site will be live at `https://yourusername.github.io/portfolio`

### Other Platforms
- Netlify: Drag and drop your folder
- Vercel: Connect your GitHub repository
- Firebase Hosting: Follow their deployment guide
